Prompts

Sent when you trigger an action from the Actions menu in each tab. Non-empty environment variable names are automatically appended.

Environment Variables

One KEY=VALUE per line (prefer uppercase, e.g. GITLAB_TOKEN=..., JIRA_TOKEN=..., CONFLUENCE_TOKEN=...). Exported into every terminal the app opens, synced to ~/.vibe-ide/env (chmod 600 — optional in ~/.zshrc: [ -f ~/.vibe-ide/env ] && source ~/.vibe-ide/env), and non-empty variable names (never values) are automatically shared with agents on Init so they use $VAR directly.
